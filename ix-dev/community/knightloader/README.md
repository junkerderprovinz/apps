# KnightLoader

[KnightLoader](https://github.com/junkerderprovinz/knightloader) is a download manager for hoster links, debrid services, torrents, Usenet and video sites. The image brings yt-dlp, ffmpeg and UnRAR and runs a private headless JDownloader for the links nothing else takes. Links come in from the web interface, the browser extension or the phone app.
